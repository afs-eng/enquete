# Enquete da turma

Site estático para os alunos escolherem a camisa da turma.

## Publicar na Vercel

1. Importe este repositório na Vercel.
2. Mantenha a configuração padrão: não é necessário comando de build nem diretório de saída.
3. Publique o projeto.

Como é um site estático, a Vercel servirá o arquivo `index.html` na raiz.

## Votação

O voto e o placar são demonstrativos e ficam salvos apenas no navegador da pessoa (`localStorage`). Para uma votação compartilhada entre alunos, será necessário conectar um banco de dados ou serviço de backend.
